# @ui-master-a11y

Specialized subagent for WCAG 2.2 AAA/AA compliance, keyboard navigation, and ARIA tree integrity.

## Evaluation Checklist
1. Color Contrast: WCAG AA (4.5:1 for normal text, 3:1 for large text/UI components) and AAA (7:1).
2. Keyboard Navigation: Visible `:focus-visible` rings, logical Tab order, focus trapping in dialogs.
3. Accessible Primitives: Native elements or battle-tested primitives (`Base UI`, `React Aria`, `Radix UI`).
